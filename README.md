# Hanzhen Yu GIS Portfolio

Static HTML/CSS/JS portfolio designed for `hanzhen-yu.com` / GitHub Pages.

## Files
- `index.html` - homepage
- `styles.css` - all styling
- `script.js` - project filters + footer year
- `projects/` - individual project pages
- `assets/` - images

## What to replace later
1. **Farmworker health project:** replace both gray image boxes in `projects/farmworker-health.html` with screenshots of the final two StoryMap maps.
2. **Historical creeks:** replace the hero placeholder and process image boxes with your ArcGIS Pro layout / georeferenced map screenshots.
3. **Map gallery:** replace the placeholder cards in `index.html` with your favorite 2D layouts and local scenes.
4. **About:** rewrite the About paragraph in `index.html` and add your resume PDF.
5. **Rock glaciers:** optionally replace the placeholder local-scene boxes on the project page with individual exports of the best 3D scenes.

## How to publish
Copy the contents of this folder into the root of your `hanzhen625/hanzhen625.github.io` repository, preserving the folder structure, then commit and push to `master` (the branch your Pages site is currently publishing).

The existing GitHub `CNAME` file containing `hanzhen-yu.com` should stay in the repository.
